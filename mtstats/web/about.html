О программе

MTstats тестовая версия

Неофициальная фанатская программа для просмотра статистики боёв по файлам реплеев «Мир танков». Работает локально: читает файлы на компьютере и ничего никуда не отправляет.

Это тестовая версия. Возможны ошибки и изменения в интерфейсе. Данные считаются по вашим реплеям и могут не совпадать с официальной статистикой игры.
Неофициальный проект. Программа не связана с Lesta Games, не одобрена и не поддерживается ею. «Мир танков» и связанные материалы — собственность правообладателя. Программа распространяется бесплатно, не для коммерческого использования.

Что программа делает

  • читает файлы .mtreplay из папки с реплеями;
  • считает статистику: урон, засвет, помощь, танкование, фарм, опыт, фраги, % побед;
  • строит графики за день, неделю, месяц, год и всё время;
  • показывает разрезы по танкам, картам и респаунам;
  • считает WN8 по ожидаемым значениям XVM, если они есть на компьютере.

Чего программа не делает

  • не изменяет клиент игры и не вмешивается в бой;
  • не читает память игры и не даёт преимуществ в бою;
  • не отправляет данные в интернет и не требует аккаунта;
  • не содержит файлов и картинок из игры — справочники собираются на вашем компьютере.

Данные и приватность

Все данные остаются у вас: настройки, база боёв и журнал лежат в %APPDATA%\MTstats. Реплеи содержат ники других игроков — они видны только вам и никуда не передаются.

Лицензия

Код распространяется по лицензии MIT. Программа использует открытые наработки сообщества: декодер BigWorld PackedSection и данные ожидаемых значений XVM (читаются из вашего кэша XVM, в комплект не входят).

Статус: демонстрационная (тестовая) сборка. Сообщения об ошибках приветствуются.
