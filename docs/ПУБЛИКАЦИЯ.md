# Как выложить MTstats в интернет

Инструкция для тех, кто **никогда не выкладывал программы**. Никаких сложных терминов:
делаем три вещи — заводим аккаунт, загружаем код, прикрепляем готовый `.exe`.

> ⚠️ Проект неофициальный, бесплатный, **не для продажи**. Это должно быть написано
> в описании репозитория и релиза (текст ниже готов).

---

## Самое короткое объяснение

GitHub — это сайт, где лежат проекты. У вас будет **страница проекта** (код, описание, картинки)
и **раздел Releases** — там лежит готовый `MTstats.exe`, который скачивают люди.

Всё, что нужно сделать:

1. Зарегистрироваться на GitHub.
2. Создать там пустой проект (репозиторий).
3. Перетащить мышкой папку с кодом в браузер.
4. Создать «релиз» и прикрепить к нему собранный exe.

Займёт 15–20 минут. Ниже — подробно.

---

## Вариант А. Без установки программ (через сайт)

### Шаг 1. Аккаунт

1. Откройте [github.com](https://github.com).
2. Нажмите **Sign up** (в правом верхнем углу).
3. Введите почту, пароль, придумайте имя пользователя (это будет частью адреса проекта).
4. Подтвердите почту — придёт письмо.

### Шаг 2. Создайте проект

1. На главной странице нажмите зелёную кнопку **New** (или «+» справа сверху → **New repository**).
2. **Repository name**: `mtstats`
3. **Description** (описание): вставьте текст:
   ```
   Неофициальная фанатская статистика боёв «Мир танков» по реплеям. Fan-made, non-commercial, beta.
   ```
4. Выберите **Public** (публичный).
5. Галочки «Add a README file», «Add .gitignore», «Choose a license» — **не ставьте**
   (эти файлы у нас уже есть).
6. Нажмите **Create repository**.

### Шаг 3. Загрузите файлы

Откроется пустая страница проекта с подсказками. Нажмите ссылку
**«uploading an existing file»** (она в блоке «Quick setup»).

Дальше:

1. Откройте в проводнике папку `D:\DSH-Work\mtstats`.
2. **Удалите на время** (или вынесите в другое место) три вещи, которые нельзя выкладывать:
   - папку `dist` (там лежит ваш exe — его загрузим отдельно, в релиз);
   - папку `build`, если она есть;
   - файлы `.spec`, если есть.
   - Также не должно быть `mtstats.db`, `config.json`, `tank_icons`, `tank_db.json`, `map_spawns.json`
     и файлов `.mtreplay`.
3. Выделите **всё содержимое** папки `mtstats` (Ctrl+A внутри папки) и **перетащите мышкой**
   в окно браузера, в область «Drag files here».
   Браузер загрузит файлы и папки.
4. Внизу нажмите зелёную кнопку **Commit changes**.

Через минуту код появится на странице проекта.

> Если браузер не хочет перетаскивать папки: нажмите **choose your files**, заходите в папки
> по одной (`mtstats`, `tools`, `docs`) и выделяйте файлы. Долго, но работает.

### Шаг 4. Проверьте, что лишнего не загрузилось

На странице проекта посмотрите список файлов. Там должны быть `README.md`, `LICENSE`,
`build_exe.py`, `run.py`, папки `mtstats`, `tools`, `docs`, `.gitignore`.

**Не должно быть**: `.db`, `.mtreplay`, `tank_icons`, `dist`, `config.json`.
Если что-то попало — откройте файл на GitHub → значок корзины (**Delete file**) → **Commit changes**.

### Шаг 5. Выложите готовую программу (Releases)

1. Соберите exe: в папке проекта откройте командную строку и выполните `python build_exe.py`.
   Появятся `dist\MTstats.exe` и `dist\MTstats-portable.zip`.
2. На странице проекта справа нажмите **Releases** → **Create a new release**.
3. **Choose a tag**: напишите `v0.9.0-beta` и нажмите **Create new tag on publish**.
4. **Release title**: `0.9.0-beta — тестовая версия`
5. **Describe this release** — вставьте:

```markdown
Тестовая версия. Неофициальная фанатская программа, не связана с Lesta Games,
не для коммерческого использования.

**Что умеет**
- читает реплеи .mtreplay, считает урон, засвет, помощь, танкование, фарм, опыт, фраги, % побед;
- графики за день / неделю / месяц / год / всё время;
- разделы по танкам, картам и респаунам, WN8;
- справочники и иконки собираются из вашего клиента игры при первом запуске.

**Установка**
1. Скачайте MTstats.exe и положите в любую папку.
2. Запустите. Если Windows предупреждает — «Подробнее» → «Выполнить в любом случае».
3. При первом запуске укажите папку с реплеями (обычно C:\Games\Tanki\replays).

Если появляется ошибка «Could not create temporary directory» — скачайте MTstats-portable.zip.

**Требования**: Windows 10/11 и включённая запись реплеев в игре.
```

6. Ниже, в разделе **Attach binaries**, перетащите `MTstats.exe` и `MTstats-portable.zip`.
7. Нажмите **Publish release**.

Всё — на странице проекта появится блок Releases с файлами для скачивания.

## Вариант Б. С программой Git (удобнее обновлять)

Так делают, когда проект будет развиваться.

1. Скачайте и установите [Git для Windows](https://git-scm.com/download/win) (всё по умолчанию).
2. Откройте «Git Bash» (появится в меню Пуск) и выполните по одной строке:

```bash
cd /d/DSH-Work/mtstats
git init
git add .
git commit -m "MTstats 0.9.0-beta"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/mtstats.git
git push -u origin main
```

3. Браузер попросит войти в GitHub — войдите.
4. Дальше шаг 5 из варианта А (релиз с exe).

Дальше обновления — три команды:

```bash
git add .
git commit -m "что изменилось"
git push
```

## Что нельзя выкладывать

| Нельзя | Почему |
|---|---|
| `data/tank_db.json`, `data/map_spawns.json` | данные из файлов игры |
| `data/tank_icons/` | нарезка игровых картинок |
| `*.db` | база с никами других игроков |
| `*.mtreplay`, `*.wotreplay` | реплеи с чужими данными |
| `config.json` | ваши личные пути |
| `dist/`, `build/`, `*.spec` | мусор сборки |

Хорошая новость: всё нужное программа собирает сама из клиента игры на компьютере пользователя,
поэтому в проекте эти файлы и не нужны. Файл `.gitignore` уже настроен и защищает от случайной
загрузки.

## Если что-то не получается

| Проблема | Что делать |
|---|---|
| «Файл больше 25 МБ» | Не загружайте exe в код. Он должен быть в **Releases** (там лимит 2 ГБ) |
| Загрузились лишние файлы | Откройте файл на GitHub → **Delete file** → **Commit changes** |
| Не понимаю, что где | Посмотрите любой популярный проект на GitHub: вкладка **Code** — файлы, **Releases** — готовые сборки |
| Не хочу GitHub | Можно выложить архив с программой на Яндекс.Диск или в облако и дать ссылку. Минус — не будет истории версий и обновлений |

## Коротко о юридическом

- В названии проекта **не используйте** «Мир танков» и «World of Tanks» — это товарные знаки.
  `mtstats` — нормально.
- В описании обязательно: «неофициальная фанатская программа, не связана с Lesta Games,
  не для коммерческого использования».
- Не выкладывайте игровые файлы, картинки и базы с данными игроков.
- Не продавайте программу и не вставляйте рекламу.
- Программа не изменяет клиент и не влияет на бой, поэтому блокировка аккаунта игрокам не грозит —
  так и напишите в описании.

Этого достаточно для спокойной публикации небольшого фанатского инструмента.
